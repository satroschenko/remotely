# Zala TV

Простой клиент Zala Yasna для Android TV (Xiaomi Mi Box): эфир, список каналов с предпросмотром, избранное,
программа передач, записи за 48 часов с точной перемоткой, автопереподключение.

Спецификация: `docs/superpowers/specs/2026-10-15-zala-tv-design.md`.

## Установка на Mi Box

1. На приставке: Настройки → Настройки устройства → Об устройстве → 7 раз нажать «Сборка».
   Затем Настройки устройства → Для разработчиков → включить «Отладка по USB» (и «Отладка по сети», если есть).
2. Узнать IP приставки: Настройки → Сеть.
3. На компьютере (в этой папке):
   ```bash
   tools/install.sh 192.168.1.50          # IP приставки
   ```
   На приставке подтвердить запрос «Разрешить отладку». Скрипт соберёт release-версию, создаст ключ подписи
   `release.jks` при первом запуске (**сохраните его** — обновления должны быть подписаны тем же ключом) и запустит приложение.
4. Первый запуск: ввести логин и пароль пультом. Затем (по желанию): удерживать OK на канале → «★ В избранное»;
   ← в списке → Настройки → «Запускать при включении приставки».

Обновление — та же команда; логин и настройки сохраняются.

## Управление (пульт Mi Box)

| В эфире | |
|---|---|
| ↑ / ↓ | следующий / предыдущий канал |
| OK или ← | список каналов (с предпросмотром) |
| → | программа передач |
| Назад | показать плашку (приложение не закрывается) |

| В списке | |
|---|---|
| OK | смотреть канал |
| удерживать OK | добавить/убрать из избранного |
| ← | меню: Избранное / Все каналы / Настройки |
| → | программа передач канала |

| В программе передач | |
|---|---|
| ← / → | день (позавчера … завтра) |
| OK на «▶ Запись» | смотреть запись |
| OK на «● Сейчас» | смотреть эфир или «⟲ С начала» |

| В записи | |
|---|---|
| OK | пауза |
| ← / → | ±30 сек (держать — быстрее) |
| ↑ / ↓ | ±5 мин |
| Назад | вернуться в прямой эфир |
