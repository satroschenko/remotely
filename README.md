## ✨ Возможности

- **Как обычный телевизор** — при запуске сразу идёт последний канал, ↑/↓ переключают каналы.
- **Список каналов с предпросмотром** — задержитесь на канале на секунду, и он начнёт играть в окошке справа.
- **Избранное** — удерживайте OK на канале; список и ↑/↓ работают только по избранным.
- **Программа передач** — позавчера … завтра, с описаниями и жанрами.
- **Записи за 48 часов** — любая прошедшая передача, а также **«⟲ С начала»** для идущей сейчас.
- **Точная перемотка** — ±30 сек (удержание ускоряет до 1 и 5 мин), ±5 мин; переход «сквозь» передачи как по ленте эфира.
- **Не зависает** — сторож зависаний, автопереподключение, повторный вход при истечении сессии,
  ожидание сети; после 5 неудачных попыток — одна большая кнопка «Повторить».
- **Настройки** — скрытие и порядок каналов, размер шрифта, качество видео, автозапуск при включении приставки, диагностика.

## 🎮 Управление

| В эфире | |
|---|---|
| ↑ / ↓ | следующий / предыдущий канал |
| OK или ← | список каналов |
| → | программа передач |
| Назад | показать информацию о передаче (приложение не закрывается случайно) |

| В списке каналов | | В записи | |
|---|---|---|---|
| OK | смотреть | OK | пауза |
| удерживать OK | ★ избранное | ← / → | ±30 сек, удержание — быстрее |
| ← | меню и настройки | ↑ / ↓ | ±5 мин |
| → | программа канала | Назад | вернуться в прямой эфир |

## 🏗 Как устроено

Официальное приложение — это WebView-обёртка ZTE над порталом `tv.zala.by`. Zala TV обращается к тому же
порталу напрямую: вход в 4 шага, JSON-эндпоинты каналов и программы, DASH-потоки без DRM (эфир и записи).
Описание API и все решения — в [спецификации](docs/superpowers/specs/2026-10-15-zala-tv-design.md).

```
ui (Compose for TV) ─► ViewModel ─► репозитории ─► SessionManager ─► ZalaApi (OkHttp)
                            │
                            └─► PlayerController ─► ExoEngine (Media3, один плеер на всё)
```

| Модуль | Что делает |
|---|---|
| `data/api` | HTTP-вызовы портала и разбор ответов |
| `data/session` | Тихий вход, обновление токена, повторный вход при потере сессии, heartbeat |
| `data/repo` | Каналы (подписка, избранное, порядок, кэш), программа передач, ссылки на потоки |
| `data/store` | Настройки (DataStore) и логин/пароль, зашифрованные ключом Android Keystore |
| `player` | Контроллер плеера: сторож зависаний, политика повторов, «лента» архива, перемотка |
| `ui` | Экраны: просмотр со слоями, вход, настройки, диагностика |

## 🛠 Разработка

Нужны JDK 21 и Android SDK 35.

```bash
tools/gw.sh :app:testDebugUnitTest   # 56 юнит-тестов
tools/gw.sh :app:assembleDebug       # отладочная сборка
tools/make-keystore.sh               # один раз: ключ подписи (не попадает в git)
tools/gw.sh :app:assembleRelease     # подписанный APK
tools/install.sh <IP приставки>      # сборка + установка на Mi Box по сети
python3 -I tools/smoke.py            # живая проверка API Zala (нужен .env)
```

## 🔒 Секреты

В репозиторий **не попадают**: `.env` (логин/пароль для smoke-теста), `release.jks` и `keystore.properties`
(ключ подписи), HAR-дампы, декомпилированный оригинал. На приставке пароль хранится зашифрованным
(AES-GCM, ключ в Android Keystore).
