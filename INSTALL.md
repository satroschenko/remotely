# Установка Zala TV на Xiaomi Mi Box

Файл для установки — **`ZalaTV-1.0.apk`** (раздел [Releases](../../releases) этого репозитория).

> ℹ️ Это приложение для **Android TV**. Формат `.ipa` — для iPhone, он здесь не подходит:
> на телефон ничего ставить не нужно, телефон используется только чтобы *передать* APK на приставку.

## Шаг 0. Разрешить установку на приставке (один раз)

1. На Mi Box: **Настройки → Настройки устройства → Безопасность и ограничения → Неизвестные источники**.
2. Включите разрешение для приложения, через которое будете устанавливать
   (*Send Files to TV* или *X-plore*, см. ниже).

## Способ 1. С телефона (проще всего)

1. Установите приложение **Send Files to TV** (SFTTV):
   - на телефон — из Google Play / App Store;
   - на Mi Box — из Google Play на приставке (поиск «Send files to TV»).
2. Скачайте `ZalaTV-1.0.apk` на телефон (откройте ссылку на Release в браузере телефона, войдите в GitHub).
3. Откройте SFTTV на **приставке** → **Receive**.
4. Откройте SFTTV на **телефоне** → **Send** → выберите `ZalaTV-1.0.apk` → выберите приставку.
5. На приставке файл появится в папке *Download*. В SFTTV на приставке выберите его → **Установить**.

## Способ 2. С флешки

1. Скопируйте `ZalaTV-1.0.apk` на USB-флешку и вставьте её в Mi Box.
2. Установите на приставке файловый менеджер **X-plore File Manager** (Google Play).
3. В X-plore откройте флешку → `ZalaTV-1.0.apk` → **Установить**.

## Способ 3. С компьютера (adb)

1. На Mi Box: **Настройки → Настройки устройства → Об устройстве → «Сборка»** — нажать 7 раз
   («Вы стали разработчиком»). Затем **Для разработчиков → Отладка по USB / по сети — включить**.
2. Узнать IP приставки: **Настройки → Сеть**.
3. На компьютере:
   ```bash
   adb connect 192.168.1.50:5555          # IP приставки; на приставке нажмите «Разрешить»
   adb install -r ZalaTV-1.0.apk
   adb shell appops set app.zalatv SYSTEM_ALERT_WINDOW allow   # для автозапуска на Google TV
   ```
   Из папки проекта всё это делает одна команда: `tools/install.sh 192.168.1.50`.

## После установки (настраивает помощник, один раз)

1. Запустите **Zala TV** (иконка появится в списке приложений; можно перетащить её в «Избранное» лаунчера).
2. Введите логин и пароль Zala пультом → **Войти**. Логин запоминается.
3. Добавьте любимые каналы: **OK** (список) → встать на канал → **удерживать OK** → «★ Добавить в избранное».
4. **← в списке → ⚙ Настройки**:
   - «Запускать при включении приставки» → **Да** (если появится экран разрешения «Поверх других приложений» —
     разрешите для Zala TV);
   - при необходимости «Размер шрифта» → «Очень крупный».

## Обновление

Новый `ZalaTV-x.y.apk` ставится поверх старого любым способом выше — логин, избранное и настройки сохраняются.
Важно: обновления должны быть подписаны тем же ключом (`release.jks` у автора), иначе Android откажется
ставить поверх и придётся удалить старую версию.

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Нет интернета, ждём…» | Проверить Wi-Fi/кабель; приложение переподключится само |
| «Не удаётся подключиться к Zala» | Нажать OK на «Повторить» |
| «Нужна помощь: неверный логин» | Настройки → Выйти из аккаунта → войти заново |
| Что-то странное | Настройки → Диагностика: последние события с временем — сфотографируйте экран и пришлите |
