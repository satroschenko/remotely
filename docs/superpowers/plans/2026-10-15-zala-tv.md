# Zala TV Implementation Plan

> Execution: Native (implemented in-session), spec: `docs/superpowers/specs/2026-10-15-zala-tv-design.md`

**Goal:** Android TV app (Mi Box) for Zala: live, channel list + preview, favorites, EPG, archive 48h with precise seek, start-over, settings, resilient reconnect.

**Stack:** Kotlin 2.1.0, AGP 8.7.3, Gradle 8.11.1 (JDK 21), compileSdk 35 / minSdk 28, Compose BOM 2024.12.01,
androidx.tv:tv-material 1.0.0, Media3 1.5.1 (exoplayer, dash, datasource-okhttp, ui), OkHttp 4.12.0,
kotlinx-serialization-json 1.7.3, coroutines 1.9.0, DataStore 1.1.1, Coil 2.7.0, JUnit 4.13.2, MockWebServer.

**Package:** `app.zalatv`

## Global Constraints
- Build with `JAVA_HOME=$(/usr/libexec/java_home -v 21)`; network calls to `*.tv.zala.by` from tools bypass shell proxy.
- No secrets in repo/logs: `.env`, `*.har` ignored; fixtures are hand-made and sanitized.
- All user-facing text in Russian; parents never see error codes.
- Retry: 5 attempts (2,4,8,16,30 s) → "Повторить" dialog; network regain → one auto attempt; bad credentials → no retry.

## Tasks
1. **Scaffold** — wrapper, catalog, manifest (leanback, banner), theme, MainActivity stub. Verify: `assembleDebug`, `testDebugUnitTest`.
2. **Core** — `Clock`, `ZalaTime` (UTC/Minsk parse+format), `RetryPolicy`, `EventLog`. Unit tests.
3. **API parsers + models** — `Channel`, `Programme`, `Session`, `ZalaParsers` (JSON, JS-object, tvodPlayUrl, session-lost). Unit tests on inline fixtures.
4. **ZalaApi** — OkHttp, cookie jar, 4-step login (+slaveeas fallback), channels, subscription, EPG, live URL, archive URL, heartbeat. MockWebServer tests.
5. **SessionManager** — mutex relogin, proactive refresh (<1h), withSession retry-once on SessionLost, heartbeat loop. Tests.
6. **Stores** — `SettingsStore` (DataStore JSON), `CredentialsStore` (Keystore AES-GCM). Tests for settings.
7. **Repositories** — Channel (subscription/hidden/order/favorites, disk cache), Epg (days, now/next, recordable), Playback. Tests for pure parts.
8. **Player logic** — `Watchdog`, `SeekAccumulator`, `ArchiveTimeline`, `PlayerController` over `MediaEngine` interface. Tests with fake engine + virtual time.
9. **ExoEngine + NetworkMonitor + AppContainer + Login screen**.
10. **Playback screen** — fullscreen, banner, up/down, status overlays, retry dialog.
11. **Channel list + preview + favorites + side menu**.
12. **EPG overlay + archive playback + archive overlay with seeking + start-over**.
13. **Settings, channel management, diagnostics, boot autostart**.
14. **Tools** — `tools/smoke.py`, `tools/install.sh`; emulator/Mi Box verification; final review.
